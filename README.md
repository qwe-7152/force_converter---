# 힘 단위 변환기

## 용도

`tkinter`로 만든 GUI 프로그램입니다. 입력한 힘의 값을 다음 단위 사이에서 변환합니다.

- `N` (뉴턴)
- `kN` (킬로뉴턴)
- `kgf` (킬로그램힘)
- `lbf` (파운드힘)

입력값은 0 이상이어야 합니다. 변환 결과는 소수점 이하 6자리까지 표시됩니다.

## 실행 명령

현재 폴더에서 다음 명령을 실행합니다.

```bash
python force_converter.py
```

Windows 환경에서는 다음 명령도 사용할 수 있습니다.

```bash
py force_converter.py
```

실행하면 `힘 단위 변환기` 창이 열립니다. 입력 단위와 출력 단위를 선택하고 값을 입력한 뒤 **변환** 버튼을 누릅니다. **단위 교환** 버튼은 입력 단위와 출력 단위를 서로 바꾸고, **지우기** 버튼은 입력값과 결과를 초기화합니다. **종료** 버튼은 프로그램을 닫습니다. 입력창에서 Enter 키를 눌러 변환할 수도 있습니다.

## 필요한 환경

- Python 실행 환경
- Python 표준 GUI 라이브러리인 `tkinter`
- 별도의 외부 Python 패키지는 필요하지 않습니다.

`tkinter`를 사용할 수 있도록 설치된 Python 환경이어야 합니다.

## 하중 데이터 분석

`load_analyzer_gui.py`는 CSV의 시간별 하중을 읽어 선택한 단면의 평균 축응력을 계산하는 GUI 프로그램입니다. 기존 `force_converter.py`와 별도로 실행되며, 원본 CSV 파일은 수정하지 않습니다.

### 실행 명령

필요한 패키지를 설치한 뒤 현재 폴더에서 실행합니다.

```bash
pip install -r requirements.txt
python load_analyzer_gui.py
```

GUI 상단의 **CSV 찾아보기** 버튼으로 파일을 선택하면 경로와 유효한 데이터 수가 표시됩니다. 단면 종류를 선택하고 치수를 입력한 뒤 **분석** 버튼을 누르면 단면적, 최대 응력, 최대 응력 해당 시간이 표시되고 하단에 `Time (s)`–`Stress (MPa)` 그래프가 표시됩니다.

### CSV 열 이름과 입력 단위

CSV 첫 행의 열 이름은 다음 두 개와 **순서까지 정확히 일치**해야 합니다.

| 열 이름 | 의미 | 단위 |
| --- | --- | --- |
| `time_s` | 측정 시간 | s (초) |
| `force_N` | 하중 | N (뉴턴) |

각 데이터 값은 Python `float()`로 읽을 수 있는 숫자여야 합니다. 예를 들어 `1.5`, `2e3` 형식을 사용할 수 있습니다. 시간과 하중의 단위는 각각 s와 N으로 고정됩니다.

### 단면별 치수와 계산식

단면 종류를 바꾸면 해당 단면 계산에 필요한 입력칸만 표시됩니다. 모든 치수의 입력 단위는 mm이며 계산된 단면적의 단위는 mm²입니다.

지원 단면 계산식은 다음과 같습니다.

- **사각형**: 폭 `b`, 높이 `h` — `A = b × h`
- **원형봉**: 직경 `d` — `A = πd² / 4`
- **원형관**: 외경 `D`, 내경 `d` — `A = π(D² - d²) / 4`
- **사각형관**: 외부 폭 `B`, 외부 높이 `H`, 두께 `t` — `A = B × H - (B - 2t) × (H - 2t)`
- **H형강**: 플랜지 폭 `B`, 전체 높이 `H`, 플랜지 두께 `tf`, 웹 두께 `tw` — `A = 2Btf + (H - 2tf) × tw`

### 이상화 단면 가정과 응력 계산

- 하중은 단면에 수직으로 균일하게 작용하는 축하중으로 가정합니다.
- 응력은 굽힘, 전단, 좌굴, 응력집중을 고려하지 않은 평균 정상응력입니다.
- 응력은 `stress_MPa = force_N / area_mm2`로 계산합니다. `1 N/mm² = 1 MPa`이므로 결과 단위는 MPa입니다.
- 사각형과 사각형관은 모서리의 곡률·용접부·모따기를 무시한 직사각형으로 가정합니다.
- 원형봉과 원형관은 완전한 동심 원으로 가정하며 나사산, 모따기, 곡률 및 제조 공차를 무시합니다.
- H형강은 플랜지 두 개와 중앙 웹 하나로 이루어진 이상적인 대칭 단면으로 가정합니다. 플랜지-웹 접합부의 곡률과 필릿은 무시합니다.
- 입력한 치수로 계산한 면적을 전체 측정 데이터에 동일하게 적용합니다.

### 오류 처리 규칙

- 파일을 선택하지 않고 **분석**을 누르면 CSV를 먼저 선택하라는 오류를 표시합니다.
- 파일을 읽을 수 없거나 인코딩·CSV 형식에 문제가 있으면 `CSV 읽기 오류`를 표시합니다.
- 열 이름이 `time_s,force_N`과 정확히 일치하지 않으면 파일을 읽지 않습니다.
- `time_s` 또는 `force_N`이 비어 있거나 숫자가 아니면 해당 행을 제외하고, 제외한 행 수를 경고로 표시합니다. 유효 데이터 수는 제외 후의 행 수입니다.
- 유효한 데이터가 하나도 없으면 그래프를 그리지 않고 안내 경고를 표시합니다.
- 치수가 숫자가 아니거나 유한하지 않거나 0 이하이면 단면 입력 오류를 표시합니다.
- 원형관은 `D > d`, 사각형관은 `2t < B` 및 `2t < H`, H형강은 `2tf < H` 및 `tw < B` 조건을 만족해야 합니다. 조건을 만족하지 않으면 분석하지 않습니다.
- 단면 종류를 변경하면 새 단면에 필요한 치수 입력칸만 표시되며, 치수는 다시 입력해야 합니다.

`load_analyzer.py`를 직접 실행하면 GUI가 아닌 기존 고정 파일 기반 콘솔 분석을 수행합니다. GUI 사용 시에는 `load_analyzer_gui.py`를 실행합니다.

## 정상 입력 예시

아래와 같이 입력합니다.

| 변환할 값 | 입력 단위 | 출력 단위 | 표시 결과 |
| ---: | :---: | :---: | ---: |
| `1` | `kN` | `N` | `1.000000 kN = 1,000.000000 N` |
| `10` | `N` | `lbf` | 약 `2.248089 lbf` |
| `0` | `kgf` | `N` | `0.000000 kgf = 0.000000 N` |

소수 및 지수 표기처럼 Python의 `float()`가 읽을 수 있는 숫자 형식도 입력할 수 있습니다. 예를 들어 `1.5`, `2e3` 등이 해당합니다.

## 오류 입력 예시

| 입력 | 동작 |
| --- | --- |
| `abc` | 숫자로 변환할 수 없으므로 `입력 오류` 대화상자를 표시합니다. |
| 빈 입력 | 숫자로 변환할 수 없으므로 `입력 오류` 대화상자를 표시하고 `숫자를 입력하세요.`라고 안내합니다. |
| `-5` | 힘은 음수가 될 수 없으므로 `입력 오류` 대화상자에 `힘은 음수가 될 수 없습니다.`를 표시합니다. |
| `1,000` | 쉼표가 포함된 문자열은 숫자로 변환할 수 없으므로 `입력 오류` 대화상자를 표시합니다. |

오류가 발생하면 입력창에 다시 포커스가 이동하고 기존 입력이 선택됩니다.

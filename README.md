# 힘 단위 변환기

## 용도

`tkinter`로 만든 GUI 프로그램입니다. 입력한 힘의 값을 다음 단위 사이에서 변환합니다.

- `N` (뉴턴)
- `kN` (킬로뉴턴)
- `kgf` (킬로그램힘)
- `lbf` (파운드힘)

입력값은 0 이상이어야 합니다. 변환 결과는 소수점 이하 6자리까지 표시됩니다.

## 실행 명령

현재 폴더에서 다음 명령을 실행합니다.

```bash
python force_converter.py
```

Windows 환경에서는 다음 명령도 사용할 수 있습니다.

```bash
py force_converter.py
```

실행하면 `힘 단위 변환기` 창이 열립니다. 입력 단위와 출력 단위를 선택하고 값을 입력한 뒤 **변환** 버튼을 누릅니다. **단위 교환** 버튼은 입력 단위와 출력 단위를 서로 바꾸고, **지우기** 버튼은 입력값과 결과를 초기화합니다. **종료** 버튼은 프로그램을 닫습니다. 입력창에서 Enter 키를 눌러 변환할 수도 있습니다.

## 필요한 환경

- Python 실행 환경
- Python 표준 GUI 라이브러리인 `tkinter`
- 별도의 외부 Python 패키지는 필요하지 않습니다.

`tkinter`를 사용할 수 있도록 설치된 Python 환경이어야 합니다.

## 하중 데이터 분석

`load_analyzer.py`는 현재 폴더의 `load_data.csv`를 읽어 하중과 응력을 분석하는 CSV 분석 프로그램입니다. 기존 `force_converter.py`와 별도로 실행되며, 원본 CSV 파일은 수정하지 않습니다.

### 입력 형식과 단위

입력 CSV의 첫 번째 행에는 다음 두 열이 정확히 있어야 합니다.

| 열 이름 | 의미 | 단위 |
| --- | --- | --- |
| `time_s` | 측정 시간 | s (초) |
| `force_N` | 하중 | N (뉴턴) |

### 필요한 라이브러리와 실행

Python 표준 라이브러리인 `csv`와 `pathlib`를 사용하며, 그래프 생성을 위해 외부 라이브러리 `matplotlib`가 필요합니다. 의존성을 설치한 뒤 현재 폴더에서 실행합니다.

```bash
pip install -r requirements.txt
python load_analyzer.py
```

### 계산과 출력

- 단면적은 코드의 `AREA_MM2 = 100.0`으로 설정되어 있으며 단위는 `mm²`입니다.
- 각 행의 응력은 `stress_MPa = force_N / area_mm2`로 계산합니다. `N/mm²`는 `MPa`와 같습니다.
- 데이터 개수, 최대 하중과 해당 시간, 최대 응력과 해당 시간, 기준 응력 `6 MPa` 초과 데이터 개수를 출력합니다.
- 시간-응력 그래프는 x축 `Time (s)`, y축 `Stress (MPa)`로 생성하며 각 데이터에 점을 표시하고 선으로 연결합니다. 최대 응력 점은 빨간색과 수치로 표시됩니다.
- 계산 결과는 `load_result.csv`에 `time_s`, `force_N`, `stress_MPa` 열로 저장합니다.
- 그래프는 `stress_plot.png`로 저장합니다.

### 오류 처리 규칙

- `time_s` 또는 `force_N` 열이 없거나 열 이름이 예상 형식과 다르면 오류를 발생시킵니다.
- 각 데이터 행의 `time_s` 또는 `force_N`이 빈 값이거나 숫자가 아니면 원본 CSV 행 번호, 열 이름, 문제값을 출력하고 해당 행을 계산과 그래프에서 제외합니다.
- 제외한 행 수와 유효한 데이터 수를 출력합니다.
- 유효한 데이터가 하나도 없으면 계산과 그래프 생성을 중단하고 안내 메시지만 출력합니다.

## 정상 입력 예시

아래와 같이 입력합니다.

| 변환할 값 | 입력 단위 | 출력 단위 | 표시 결과 |
| ---: | :---: | :---: | ---: |
| `1` | `kN` | `N` | `1.000000 kN = 1,000.000000 N` |
| `10` | `N` | `lbf` | 약 `2.248089 lbf` |
| `0` | `kgf` | `N` | `0.000000 kgf = 0.000000 N` |

소수 및 지수 표기처럼 Python의 `float()`가 읽을 수 있는 숫자 형식도 입력할 수 있습니다. 예를 들어 `1.5`, `2e3` 등이 해당합니다.

## 오류 입력 예시

| 입력 | 동작 |
| --- | --- |
| `abc` | 숫자로 변환할 수 없으므로 `입력 오류` 대화상자를 표시합니다. |
| 빈 입력 | 숫자로 변환할 수 없으므로 `입력 오류` 대화상자를 표시하고 `숫자를 입력하세요.`라고 안내합니다. |
| `-5` | 힘은 음수가 될 수 없으므로 `입력 오류` 대화상자에 `힘은 음수가 될 수 없습니다.`를 표시합니다. |
| `1,000` | 쉼표가 포함된 문자열은 숫자로 변환할 수 없으므로 `입력 오류` 대화상자를 표시합니다. |

오류가 발생하면 입력창에 다시 포커스가 이동하고 기존 입력이 선택됩니다.
